# Akram PhoneLoc

Site vitrine pour un local de vente, achat, réparation et échange de téléphones à Oran.

## Comment lancer le site

1. Ouvrez le dossier du projet dans VS Code.
2. Faites un clic droit sur `index.html` et choisissez "Open with Live Server" si vous avez l'extension Live Server.
3. Sinon, ouvrez le fichier directement dans le navigateur.
4. Pour l'interface admin, ouvrez `admin.html`.

## Fonctionnalités

- Page d'accueil moderne et mobile-friendly
- Catalogue de téléphones avec prix et description
- Bouton WhatsApp direct
- Formulaire de contact pour les clients
- Interface admin locale pour ajouter et supprimer des produits
- Stockage des produits dans le navigateur via `localStorage`
